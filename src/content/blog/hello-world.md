> Every post is just a Markdown file in `src/content/blog/`.

This is a sample post. Copy `_template.md`, rename it, and start writing — the
filename becomes the URL (`/blog/hello-world`).

## Formatting

You get **bold**, *italics*, `inline code`, lists, quotes, and code blocks:

```js
console.log('Hello from my portfolio')
```

## Attachments

Links to `.pdf`, `.docx`, `.pptx`, `.xlsx` or `.zip` files render as styled
download cards automatically.
